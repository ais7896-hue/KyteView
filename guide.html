01

快速開始與空白鍵瞬開

KyteView 啟動後會安靜常駐於 Windows 右下角系統托盤。您不需要學習繁瑣的指令，只需在 Windows 檔案總管或桌面保持自然的習慣操作：

開啟 / 關閉預覽

選中檔案按下 Space 立即彈出；再按一次或按 ESC 瞬間關閉。

連續切換瀏覽

預覽視窗開啟時，直接按鍵盤方向鍵 ↑ ↓ ← →，預覽視窗會無縫切換當前檔案。

焦點保護機制：KyteView 彈出預覽視窗時，不會奪走檔案總管的鍵盤焦點，因此您可以持續以方向鍵、PageUp/Down 在檔案總管中自由移動。
02

智慧避讓 (Smart Offsetting)

傳統預覽工具（如 macOS QuickLook）總是死板居中彈出，在 Windows 多欄檔案總管挑選檔案時，常會擋住游標前後項目的檔名。KyteView 導入自適應動態避讓：

檔案總管靠左時
預覽視窗自動偏移至螢幕右半側展示，完整露出檔案清單
檔案總管靠右時
預覽視窗自動鏡像偏移至螢幕左半側，兩側視窗互不遮蔽
多螢幕環境下
自動感應滑鼠所在顯示器與 DPI 縮放比例，始終呈現最佳尺寸
03

側邊釘選模式 (Pin to Side / Split View)

需要一邊查看合約/規格書、一邊打字輸入時，按一下 Tab 鍵，視窗立刻鎖定為固定常駐狀態：

釘選模式三大特性：

  • • 視窗恆定置頂 (Always-on-Top)：切換其他任何軟體輸入時，預覽視窗絕不沉底消失。
  • • 釋放焦點 (Focus Freedom)：可任意點擊瀏覽器、Word、Excel，預覽內容保持清晰對照。
  • • 再按一次 Tab 解除：按鍵即刻切換為一般預覽隨選隨開模式，彈性流暢。
04

壓縮包目錄樹與單檔拖曳抽出

KyteView 徹底顛覆了以往處理壓縮包（.zip, .7z, .rar, .tar.gz）必須「整包解壓縮 $ ightarrow$ 找檔案 $ ightarrow$ 刪除暫存」的痛苦流程：

STEP 1

5ms 極速讀取目錄樹

僅讀取檔案尾端中央目錄，不解壓任何多餘內容，千筆檔案瞬間呈現 QTreeView 階層目錄樹與精確檔案大小。

STEP 2 (殺手級功能)

單檔直接拖曳抽出

按住滑鼠左鍵選中某個檔案，直接向外拖到桌面或資料夾，背景自動秒解該單檔，瞬間寫入目標路徑！

05

8 方向邊緣自由縮放與尺寸記憶

為解決無邊框預覽視窗無法隨意調整大小的難題，KyteView 內建精準的原生 8 方向邊緣感知引擎，提供如傳統視窗般的流暢縮放體驗：

8 個邊界感知觸發區

滑鼠移至預覽視窗的上、下、左、右四邊或四個對角，鼠標會自動變換為對應縮放雙向箭頭（↔、↕、⤡、⤢），按住即可直接拖拉擴展視窗。

自動記憶個人黃金尺寸

拖曳調整視窗後，軟體會自動儲存尺寸；下次按空白鍵瞬開同類型檔案時，將自動以您最習慣的最佳視角展開呈現。

06

免裝 Office 簡報與極速 Office 預覽

許多工作電腦未安裝微軟 Office 或受限於授權。KyteView 具備業界領先的雙軌解碼引擎：

PPTX 原生解析器（電腦完全不需安裝 PowerPoint）

底層直接解構 OpenXML 投影片 XML 與關聯媒體，自動提取高解析度預渲染縮圖，零載入等待，並提供換頁按鈕快速閱覽全簡報。

Word / Excel 高速向量快取

若本機已安裝 Office，KyteView 會自動調用 COM 高速向量快取引擎，排版 100% 精準不跑版；若無安裝 Office，則以結構化文字預覽確保資料秒開不中斷。

07

GPU 硬體加速影音與黑膠音訊播放

KyteView 不打包肥大且耗電的外部 FFmpeg 播放器，而是直接調用微軟 Windows Media Foundation (WMF) 進行 GPU 硬體解碼：

影片播放 (.mp4, .mov, .webm, .mkv)

• 4K 影片毫秒級秒開，CPU 佔用近乎 0%。
• 支援進度拖曳條，懸浮控制列在滑鼠靜止 2 秒後自動淡出隱藏。

音訊播放 (.mp3, .flac, .wav, .m4a)

• 經典現代黑膠唱片旋轉封面視覺動效。
• 支援進度拖曳條、時間碼即時顯示。
• 輕量零負擔，音質無損原音重現。

08

視覺感知狀態膠囊 (HUD) 與長按微透視

預覽檔案時，最怕繁雜的多餘彈窗打斷工作心流。KyteView 採用頂級微動態設計，讓資訊以極致低調優雅的方式即時反饋：

右下角待命提示膠囊 (Status Pill HUD)

當您切換至檔案總管時，螢幕右下角會以毛玻璃動畫短暫淡入「⚡ KyteView 待命中 · [Space] 預覽」，提示系統已就緒，低調美觀且完全不干擾工作。

長按 Alt/Ctrl 瞬間透視底層

預覽視窗遮擋住底層檔案名稱或背景桌面時，只需長按 Alt 或 Ctrl 鍵，視窗瞬間淡化為 20% 半透明；鬆開按鍵即刻恢復 100% 清晰預覽！

09

系統托盤常駐管理與單一實例守護

KyteView 啟動後安靜常駐於 Windows 右下角系統托盤，記憶體佔用極低（平常小於 60MB），不拖慢系統效能：

托盤右鍵快捷選單

右鍵點擊托盤圖示可隨時開啟偏好設定、切換開機自啟動、查看授權狀態、複製診斷資訊或優雅結束程式。

單一實例 (Mutex) 守護

底層採用 Windows 原生具名互斥鎖，避免多次重複點擊導致重複開程式，自動保持全域單一守護實例。

開機靜默隨選即開

支援 Windows 開機時背景靜音載入，免去每次手動點開的麻煩，開機後在檔案總管按空白鍵隨時可開。

偏好設定功能與常見問題 (FAQ)

點擊預覽視窗右上角的齒輪圖示 ⚙️ 或右下角系統托盤圖示，即可開啟完整偏好設定面板：

外觀風格與 Win11 Mica 效果

提供深色 (Dark)、淺色 (Light) 或跟隨 Windows 系統主題。支援開啟 Windows 11 原生 Mica / Acrylic 半透明亞克力毛玻璃視窗底色。

視窗模式與避讓開關

可自由切換「動態自適應螢幕」或「固定記憶尺寸」；並可一鍵啟用或關閉「智慧避讓偏移機制 (Smart Offset)」。

一鍵複製系統診斷資訊

設定面板底部提供「📋 複製系統診斷資訊」，自動收集 OS 版本、DPR 螢幕縮放比與 Office COM 引擎狀態，方便向客服快速回報排除問題。

授權中心與裝置換機管理

直觀查看目前方案（14 天免費試用剩餘天數 / 永久專業版），支援輸入序號一鍵線上啟用，以及更換新電腦時自主「解除綁定」釋放額度。

常見問題與解答

Q: 為什麼在檔案總管按空白鍵沒有反應？

請檢查 Windows 右下角系統托盤是否有 KyteView 執行圖示。若執行緒被防毒軟體攔截，請至安全中心將其新增至允許清單。

Q: 一組序號可以在幾台電腦使用？更換電腦怎麼辦？

每組專業版序號支援 2 台個人電腦同時授權綁定。若更換新電腦，可在舊電腦的「偏好設定 ➔ 授權」點選「解除綁定」，額度將即時釋放給新電腦使用。

Q: 如何讓 KyteView 開機時自動啟動？

在安裝時勾選「開機時自動啟動」，或在偏好設定中勾選「開機自動啟動」即可。
