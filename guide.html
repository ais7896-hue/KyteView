01

快速開始與空白鍵瞬開

KyteView 啟動後會安靜常駐於 Windows 右下角系統托盤。您不需要學習繁瑣的指令，只需在 Windows 檔案總管或桌面保持自然的習慣操作：

開啟 / 關閉預覽

選中檔案按下 Space 立即彈出；再按一次或按 ESC 瞬間關閉。

連續切換瀏覽

預覽視窗開啟時，直接按鍵盤方向鍵 ↑ ↓，預覽視窗會無縫切換當前檔案。

焦點保護機制：KyteView 彈出預覽視窗時，不會奪走檔案總管的鍵盤焦點，因此您可以持續以方向鍵、PageUp/Down 在檔案總管中自由移動。
02

智慧避讓偏移機制 (Smart Offsetting)

傳統預覽工具（如 macOS QuickLook）總是以螢幕正中央彈出，在 Windows 往往直接蓋住檔案總管選取的檔案，導致使用者看不到前後項目的檔名。KyteView 導入全自動動態幾何避讓：

檔案總管靠左側時
預覽視窗自動智慧偏移至螢幕右側
檔案總管靠右側時
預覽視窗自動智慧偏移至螢幕左側
檔案總管全螢幕最大化時
視窗果斷靠向右側，留出左側樹狀導航與清單
03

快速側邊釘選模式 (Pin to Side / Split View)

當您需要逐一審核幾百張採購合約、相片或工程圖紙時，浮動視窗可能會顯得零碎。這時按下鍵盤 Tab 鍵，即可進入專屬的 Split View 分割檢閱模式：

釘選模式操作方式：

  • 預覽期間隨時按 Tab 鍵，視窗立即全高度靠齊螢幕右側 1/3。
  • 左側 2/3 保留給檔案總管，搭配方向鍵下滾，享受如專屬審查系統般的並排檢視。
  • 再按一次 Tab 或點擊右上角「◨」按鈕即可解除釘選，回歸自適應浮動視窗。
04

壓縮包目錄樹、單檔抽出與巢狀預覽

KyteView 徹底顛覆了以往處理壓縮包（.zip, .7z, .rar, .tar.gz）必須「整包解壓縮 $\rightarrow$ 找檔案 $\rightarrow$ 刪除暫存」的痛苦流程：

STEP 1

5ms 讀取目錄樹

僅讀取檔案尾端中央目錄，不解壓任何多餘內容，千筆檔案瞬間呈現 QTreeView 階層目錄樹。

STEP 2 (殺手級)

單檔直接拖曳抽出

按住滑鼠左鍵選中某個檔案，直接向外拖到桌面或資料夾，背景自動解壓該單檔，瞬間寫入目標路徑！

STEP 3

巢狀預覽與返回

在樹狀圖中按 Enter 或雙擊，就地預覽包內文字/圖片；按 Backspace 瞬間重回目錄樹！

05

微軟 Office 簡報與文件免裝 Office 預覽

不用花費數秒等待 Microsoft PowerPoint 或 Word 載入，KyteView 採用輕量原生解析技術：

PowerPoint (.pptx / .ppt)

• 封面縮圖 2~5ms 秒開：優先載入微軟封裝時內建的真實高解析封面圖。
• 多頁大綱條列：解析每頁標題、要點清單（Bullets）與配圖。
• 專屬 16:9 比例畫布：預設以寬螢幕比例開啟，兩側絕不留黑邊。
• 底部懸浮膠囊翻頁：支援 PageUp/Down、鍵盤左右鍵與滑鼠滾輪自由翻頁。

Word 文件 (.docx / .doc)

• 採用純 Python 輕量解析引擎轉為標準 HTML 排版。
• 完整保留標題層級、粗體、斜體、表格資料、項目符號清單與內嵌圖片。
• 舊版二進位 .doc 自動平滑降級為屬性卡片，附帶一鍵預設程式開啟按鈕。

06

GPU 硬體加速影音播放與黑膠音訊動效

KyteView 不打包肥大且耗電的外部 FFmpeg 播放器，而是直接調用微軟 Windows Media Foundation (WMF) 進行 GPU 硬體解碼：

影片播放 (.mp4, .mov, .webm, .mkv)

• 4K 影片毫秒級秒開，CPU 佔用近乎 0%。
• 按 Space 切換暫停與播放。
• 按鍵盤 ← / → 進行 5 秒快轉/倒帶。
• 懸浮控制列在滑鼠靜止 2 秒後自動淡出隱藏。

音訊播放 (.mp3, .flac, .wav, .m4a)

• 經典現代黑膠唱片旋轉封面視覺動效。
• 支援進度拖曳條、時間碼即時顯示。
• 輕量零負擔，音質無損原音重現。

07

長按微透機制 (Peek Through) 與自訂縮放

遇到預覽視窗恰好遮擋了底層檔案名稱或桌面內容時，無需將視窗移開：

長按看穿背景：

在預覽視窗開啟時，按住鍵盤 Alt 或 Ctrl 不放，視窗會瞬間切換成 15% 半透明透視狀態。放開按鍵後即刻恢復。

自由縮放至 200x150：

視窗右下角附帶精緻 Resize Grip，支援無限制拖曳縮小至 200x150，在多螢幕小視窗環境下依然維持極佳相容性。

08

偏好設定與常見問題 (FAQ)

在任何時候按下 Ctrl + , 或點擊工具列齒輪圖示，即可喚出偏好設定面板：

Q: 如何更換深色與淺色風格？

在設定視窗的「外觀與主題」分頁，可隨時選擇跟隨系統、深色模式或淺色模式，並可開啟或關閉 Windows 11 原生 Mica 毛玻璃效果。

Q: 為什麼在檔案總管按空白鍵沒有反應？

請檢查 Windows 右下角系統托盤是否有 KyteView 執行圖示。若執行緒被防毒軟體攔截，請至安全中心將其新增至允許清單。

Q: 如何讓 KyteView 開機時自動啟動？

在安裝時勾選「開機時自動啟動」，或在偏好設定中勾選「開機自動啟動」即可。
