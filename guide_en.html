01

Quick Start & Spacebar Instant Launch

Once KyteView is launched, it resides quietly in your Windows system tray. You don't need to learn any complex commands—simply use standard file browsing gestures:

Open / Close Preview

Select any file and tap Space for instant preview; press Space again or ESC to close.

Continuous Navigation

While preview is active, use arrow keys ↑ ↓ ← → to seamlessly switch between items in Explorer.

Non-Stealing Focus Architecture: KyteView never steals keyboard focus from Windows Explorer when popping up, allowing you to freely navigate files without interruptions.
02

Smart Offsetting Mechanics

Traditional preview tools blindly center windows on screen, obscuring file lists and filenames in multi-pane Explorer views. KyteView introduces adaptive dynamic offsetting:

Explorer on the Left
Preview automatically offsets to the right side of the screen, leaving the file list fully visible.
Explorer on the Right
Preview dynamically mirrors to the left side, eliminating overlap between active windows.
Multi-Monitor Setups
Automatically detects the active monitor and per-monitor DPI scaling, ensuring optimal crispness.
03

Side Pinning Mode (Tab / Split View)

Need to reference a contract, spec sheet, or reference image while typing? Press Tab to lock the preview into pinned split view:

Three Core Characteristics of Pinning:

  • • Always-on-Top Window: Remains pinned on top even when clicking Word, Excel, or code editors.
  • • Focus Freedom: Type and click freely in any target application while keeping reference material clearly in view.
  • • Tap Tab Again to Unpin: Immediately toggles back to normal auto-dismiss preview mode.
04

Archive Tree & Single-File Drag Extraction

KyteView completely transforms how you handle compressed archives (.zip, .7z, .rar, .tar.gz), removing the tedious cycle of "extract whole archive → find file → delete temp folder":

STEP 1

5ms Instant Central Directory Read

Reads only the central directory headers without decompressing bulk data. Instantly displays thousands of items in an interactive tree view with file sizes.

STEP 2 (Killer Feature)

Single-File Drag Extraction

Hold down the left mouse button on any single file inside the archive and drag it directly to the desktop or any folder. KyteView extracts only that specific file on the fly!

05

8-Directional Edge Resizing & Window Memory

Frameless windows in Windows often sacrifice natural resizing. KyteView features a native 8-directional edge sensor engine that behaves just like a standard system window:

8 Interactive Resize Hitboxes

Hover over any of the top, bottom, left, right edges or four corners. The cursor automatically transforms into resize arrows (↔, ↕, ⤡, ⤢) for smooth dragging.

Persistent Golden Ratio Memory

After resizing, your custom window dimensions are remembered per category. Next time you hit Spacebar, the preview expands to your preferred dimensions.

06

Zero-Install PPTX & High-Speed Office Viewer

Many workstations lack Microsoft Office or have restricted licensing. KyteView incorporates an industry-leading dual-path rendering engine:

Native PPTX Parser (Zero PowerPoint Installation Required)

Directly decodes OpenXML slides and relationships to extract high-resolution rendered thumbnails with zero cold-start delay, offering slide switching controls.

Word / Excel Vector Cache Acceleration

When Office is present, KyteView connects to COM vector caching for 100% faithful layout fidelity; without Office, it seamlessly falls back to structured text extraction.

GPU Hardware Accelerated Media & Vinyl Audio Player

Video Playback (.mp4, .mov, .webm, .mkv)

• 4K video opens in milliseconds with near 0% CPU consumption.
• Interactive seekbar; floating controls auto-fade after 2 seconds of inactivity.

Audio Playback (.mp3, .flac, .wav, .m4a)

• Elegant rotating vinyl record animation with embedded cover art.
• Real-time timecode readout and interactive scrubbing bar.
• Zero system overhead and lossless audio fidelity.

Status Capsule HUD & Hold to Peek Translucency

Intrusive UI popups interrupt creative flow. KyteView utilizes micro-motion design to provide feedback in the most subtle, elegant manner:

Bottom-Right Status Pill HUD

When switching to Explorer, a frosted capsule briefly fades in showing "⚡ KyteView Ready · [Space] Preview", quietly letting you know the daemon is active without disruption.

Hold Alt/Ctrl to Peek Beneath

If the preview covers file names or desktop icons underneath, hold Alt or Ctrl to make the window instantly fade to 20% opacity; release to restore 100% clarity!

09

System Tray Management & Single Instance Guard

KyteView runs as a lightweight daemon in the Windows notification area, consuming under 60MB RAM with zero impact on system responsiveness:

Tray Context Menu

Right-click the tray icon to quickly access Preferences, toggle Autostart, inspect license status, copy diagnostics, or exit.

Mutex Guard

Native Windows named mutex locks prevent duplicate daemon processes from launching if you click the executable repeatedly.

Silent Autostart

Supports starting quietly minimized in the background at Windows boot, ready for Spacebar previews without manual launching.

Frequently Asked Questions

Q: Why is there no response when pressing Space in Windows Explorer?

Please verify that KyteView is running in your Windows system tray. If your antivirus intercepted the background hook, please add KyteView to your security whitelist.

Q: How many devices can one license key activate? How do I transfer to a new PC?

Each Pro license permits simultaneous activation on 2 personal PCs. When upgrading to a new PC, open "Preferences ➔ License" on the old machine and click "Deactivate Device" to instantly free up the slot.

Q: How do I make KyteView launch automatically on Windows boot?

Check "Launch at system startup" during the installer setup, or toggle the "Autostart on boot" switch in Preferences at any time.

Q: What is the maintenance period and update policy for one-time purchases?

Licenses are one-time perpetual purchases including one year of free maintenance and bug fixes. If future major operating system overhauls (such as major Windows version upgrades) necessitate substantial software refactoring, new major releases will be sold separately.
