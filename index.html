FAQ

常見問題解答

KyteView 支援哪些 Windows 作業系統？

KyteView 專為 64 位元 Windows 10 (1809 以上) 與最新 Windows 11 深度設計，完美原生支援深色模式（Dark Mode）、淺色模式以及 Windows 11 Mica / Acrylic 毛玻璃半透明材質。

預覽 Word 或 PowerPoint 需要在電腦安裝微軟 Office 嗎？

完全不需要！KyteView 採用純原生輕量解析引擎，PPTX 透過內嵌縮圖 2~5ms 秒開並支援多頁大綱條列；DOCX 透過純 Python 輕量轉標準 HTML 渲染，即使電腦完全沒有安裝 Office 也能流暢秒開。

防毒軟體或 Windows Defender 是否會誤報？

由於 KyteView 使用 Windows 底層低階鍵盤鉤子（Low-Level Keyboard Hook）監聽檔案總管中的空白鍵（Space），部分防毒軟體首次執行時可能會出現提示。KyteView 為純本地端離線運作工具，絕不連網傳輸您的任何個人檔案，請安心點擊允許。
